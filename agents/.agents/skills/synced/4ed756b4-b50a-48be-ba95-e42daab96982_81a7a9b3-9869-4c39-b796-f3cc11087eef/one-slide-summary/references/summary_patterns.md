# ONE Summary Slide — Layout Pattern Reference

## 実装方法

レイアウトの実装は **`one-slide-generate` スキルのヘルパー関数とデザイントークン** を使用する。独自にPptxGenJSのコードをゼロから書かない。

### 参照先
- デザイントークン（色・フォント・スペーシング）: one-slide-generate の `design_tokens.md`
- PptxGenJSヘルパー関数: one-slide-generate の `pptxgenjs_guide.md`
- レイアウトパターン: one-slide-generate の `layout_patterns.md`

## Mode A: エグゼクティブサマリー

### 推奨: KPI-Row パターン

one-slide-generate の `makeKpiRowSlide()` を参考に1スライド生成:

```
┌─────────────────────────────────────────┐
│ [Title: レポートの最重要結論]              │ 28-32pt Bold
├─────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐       │
│ │ KPI 1  │ │ KPI 2  │ │ KPI 3  │       │ 3-4 cards
│ │ 48pt   │ │ 48pt   │ │ 48pt   │       │ F0F3F6 BG
│ │ label  │ │ label  │ │ label  │       │
│ └────────┘ └────────┘ └────────┘       │
│                                         │
│ [Core insight from report — 1-2 lines]  │ 18pt
│                                         │
│                      Source: レポート名  │ 14pt 8C909B
└─────────────────────────────────────────┘
```

## 88%ルール（底部オーバーフロー防止）

コンテンツはスライド高さの88%以内に収める（y ≤ 4.95"）。はみ出す場合:
1. KPIカード数を減らす（4→3）
2. テキストを短縮
3. 最低優先度の要素を削除

**フォントを最小サイズ以下に縮小して詰め込むのは禁止。コンテンツを削る。**

## コンテンツ選定

1ページに収めるため、元レポートから**最も重要なデータのみ**抽出:
- KPI: **3-4個**（全部ではない）
- チャート: **1つ**（最も説得力のあるもの）
- インサイト: **1つ**（核心的な結論）

残りは「詳細はレポート本体参照」で割り切る。
