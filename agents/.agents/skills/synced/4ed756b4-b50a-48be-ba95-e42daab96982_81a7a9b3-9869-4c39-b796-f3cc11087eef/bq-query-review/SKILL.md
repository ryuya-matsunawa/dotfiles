  BigQueryクエリの集計条件一貫性・品質を担保するレビュースキル。
  以下のフレーズが含まれる場合は必ずこのスキルを使用すること：
  - 「クエリをレビューして」「このクエリ確認して」「集計条件が合っているか見て」
  - 「前回と条件が一致しているか確認して」「クエリのチェックして」「期間が正しいか確認して」
  - クエリ（SQLコード）が貼り付けられて確認・レビューを求められた場合
  - 新規クエリ生成の前に集計条件を固定したい場合（「条件を固定して」「期間を合わせて」）
  - マストバイレポート・0次分析・N1分析など、分析着手前に条件を確認したい場合
  - 「集計条件マスターを作って」「マスター条件を固定して」
  - 「集計期間を確認して」「この条件で問題ないか確認して」
  - 「品質だけチェックして」「マスターなしでレビューして」

# bq-query-review スキル

スキル起動時に、以下の手順で指示を読み込み、その内容に従って処理を実行してください。

1. まず以下のNotionページの指示を読み込んでください：
   https://www.notion.so/373d48a3c2cb8157b4d9dd3e18675a52

2. 上記が取得できない場合は、以下のGoogle Driveフォルダ内にある最新のmdファイルを読み込んでください：
   フォルダID: 1pgY64u-MbiyK6zdI50z7xAdKvMI7H0Od

   手順：
   - GDriveツールでフォルダ内の `bq-query-review` を含むファイルを一覧取得する
   - `diff` を含むファイル名は除外する
   - ファイル名が `bq-query-review_YYYYMMDD.md` パターン（末尾に8桁の日付）に一致するものを抽出する
   - ファイル名末尾のYYYYMMDD（8桁数値）が最大のものを1件選択して読み込む
   - 該当するファイルがない場合は、modifiedTimeが最も新しいファイルにフォールバックする
