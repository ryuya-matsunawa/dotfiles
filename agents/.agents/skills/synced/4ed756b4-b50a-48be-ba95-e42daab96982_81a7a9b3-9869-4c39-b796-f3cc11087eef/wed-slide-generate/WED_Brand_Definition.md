## 0. Brand Story

### Mission
"Create a world where every purchase sparks excitement."

### Who WED Is
WED transforms everyday spending from "just a payment" into an experience. Facing users' reality head-on, enabling experiences through technology, and creating new norms — these are WED's operating principles.

### Brand Hierarchy
| Brand | Position | Description |
|-------|----------|-------------|
| **WED** | Company | The foundation of trust, technology, and ambition. The base for all products and services |
| **ONE** | Flagship Product | The frontline of WED's user experience. Transforms spending experiences through receipt cashback and more |
| **PMN** | B2B Business | Performance Media Network. Extends WED's experience, operations, and technology into B2B contexts. Connects manufacturers' marketing efforts to "purchase outcomes" |

**Note**: PMN is not a "separate brand" but an extension of WED's accumulated technology and operations into a business line. The experience, operations, and data/technology built through ONE form the foundation of WED's strengths and credibility.

### "WED-ness" Expression Principles
Express through actions and facts, not adjectives:
- **Face users' reality** — integrity in on-the-ground operations, fraud prevention, and quality
- **Enable experiences through technology** — concrete systems like receipt parsing and data utilization
- **Create new norms** — the challenge of transforming the spending experience

## 1. Color Palette

### Core Colors (Primary Use)
| Name | HEX | Usage |
|------|-----|-------|
| Beige Light | #D2D2C6 | Background color, base color. WED's signature identifier color |
| Beige Dark | #6D695D | Accent elements: emphasis, highlights, key data, chart fills. Warm olive-gray tone |
| Black | #000000 | Headings, body text |
| White | #FFFFFF | Backgrounds, text on dark backgrounds |

### Slide Background Rules (dual background system)
- **Content slides** (tables, dashboards, charts, data-heavy): #FFFFFF background (default for most slides, ~60-70%)
- **Brand slides** (statement, pull quote, visual pause): #D2D2C6 background (~30-40%)
- Mix both in every deck to create visual rhythm. Never all-white or all-beige.

### Color Usage Rules
- Use only core colors (Beige Light, Beige Dark, Black, White)
- On #D2D2C6 slides: White (#FFFFFF) for card fills and content areas
- Beige Dark (#6D695D) for accent elements (emphasis, highlights, key data)
- Dark variations (section dividers, etc.): Black or Beige Dark (#6D695D) background + White text
- Table styling: Use #FFFFFF slide background for table slides. #6D695D header row (#FFFFFF text) + #D2D2C6/#FFFFFF alternating body rows (#000000 text), rounded outer frame

### Text Color Rules (mandatory — apply to every text element)
- If element background = #D2D2C6 or #FFFFFF → text color MUST be #000000
- If element background = #6D695D or Black → text color MUST be #FFFFFF
- KPI numbers: #6D695D on light backgrounds (sole exception)
- Body text is always #000000 — never #6D695D, never gray

## 2. Typography

### Font Specification
- **Japanese**: Zen Kaku Gothic New
- **English**: Zen Kaku Gothic New (ideally Paralucent)

### Text Style Guide
| Element | Weight | Size | Color |
|---------|--------|------|-------|
| Slide title | Bold | 28-32pt | Black |
| Section heading | Bold | 20-24pt | Black / White (depends on background) |
| Body text | Regular | 18-20pt | Black |
| KPI label | Regular | 16pt | Beige Dark (#6D695D) |
| Footnote / Source | Regular | 14pt | Beige Dark (#6D695D) |
| Numbers / KPIs | Bold | 48-72pt | Beige Dark (#6D695D) |

**Minimum font size: 14pt (footnotes only). Body text MUST be 18pt or larger.**

### Text Density Guidelines (per element)
| Element | Max Words | Rationale |
|---------|-----------|-----------|
| Slide title | 10 words | Short conclusion, not description |
| Bullet point | 10 words each | One idea per line |
| Table cell | 8 words | Scannable at glance |
| Card body | 40 words | Less text = larger font |

All text must be readable from the back of a meeting room. Less text per element forces larger, more readable fonts.

## 3. Design Tone & Manner

### Core Principles
- **Minimal**: Eliminate unnecessary decoration, convey information concisely
- **Refined**: Create a professional, intelligent impression
- **Breathing room**: Maintain consistent margins and spacing:
  - Slide edges: ~6% horizontal, ~8% vertical margins
  - Title-to-body gap: 1.5× title height
  - Card-to-card gap: ~5% of card width
  - Never push content to edges. Always maintain "breathing" whitespace

### Layout Principles
- One slide = one message as the baseline
- Make information hierarchy clear (Title → Subtitle → Body → Supplement)
- Left-aligned by default; centering only for title slides and section dividers
- Maintain grid-based, orderly layouts
- Use rounded corners (8-12px radius) consistently on cards, tables, and content boxes

### Information Density
Aim for the quality of an actual business analysis deck, not a series of cover pages:
- **Data visualization**: Actively use precise charts (stacked bar, waterfall, line) and detailed data tables with rows and columns
- **Structured frameworks**: Visualize analysis using strategy diagrams and 2×2 matrices composed of thin, refined lines
- **Asymmetric layouts**: Prefer asymmetric splits (60/40 or 70/30) over uniform 50/50 grids. Use typography as design — one oversized number (48pt+) or a bold pull-quote can replace a shape. Vary element heights rather than using equal-sized boxes

### Element Count Guidelines (per slide type)
| Slide Type | Recommended Max | Rationale |
|------------|----------------|-----------|
| Title / Section divider | 2-3 elements | Purpose is impression. Minimize information |
| Text / Message | 3 elements (title + conclusion + evidence) | One slide = one message principle |
| Bullet points | Title + 3-4 items | Audience loses track beyond 4 items |
| KPI / Numbers | 2-3 numbers | More than 3 loses focus |
| Chart / Graph | 1 chart + title + 1 insight line | Let the chart speak. Don't over-explain |
| 2-3 column cards | Same as column count (2-3 elements per card) | Cards themselves serve as dividers |
| Data table | 5-7 rows × 4 columns max | Beyond this = handout, not presentation |

## 4. Slide Composition Patterns

### Structural Slides (Presentation skeleton)
| Type | Description | Notes |
|------|-------------|-------|
| **Title (Cover)** | Presentation name + subtitle + date | Use existing template |
| **Table of Contents** | Section list | Use existing template |
| **Section Divider** | Section name only (Beige Dark / Black background recommended) | Use existing template |
| **Closing** | Conclusion | Use existing template |

### Content Slides (Select based on content)
| Type | Usage |
|------|-------|
| Text | Explanations, descriptions |
| Bullet points | Key point organization (3-5 items) |
| 2-column split | Comparison, Before/After |
| 3-column split | Feature introduction, step explanation |
| 4-quadrant | 2×2 matrix analysis |
| KPI / Numbers | Large numbers + explanatory text |
| Charts / Graphs | Data visualization + insights |
| Data table | Detailed row/column data presentation |
| Summary / Next Steps | Action item organization |

### Content Layout Patterns (vary — never repeat 3x consecutively)
| Pattern | Frequency | Structure |
|---------|-----------|-----------|
| **Left-Right 60/40** | PRIMARY (30%+) | Large area = chart/analysis, Small area = takeaways/data table |
| **Dashboard** | Regular | Top 3-4 white rounded KPI cards + bottom chart/table |
| **Statement+Evidence** | Regular | Top: 28pt bold conclusion in white rounded box → bottom: supporting data |
| **Full-Width Table** | Regular | Use #FFFFFF slide background. #6D695D header row, #D2D2C6/#FFFFFF alternating body rows, rounded outer frame. 4+ rows |
| **2×2 Matrix** | Regular | Four white rounded quadrants on #D2D2C6, each with label+analysis |
| **Process Flow** | Regular | 3-5 white rounded nodes connected by thick visible #6D695D arrows/lines (MANDATORY). Key step filled #6D695D |

### Visual Rhythm (Slide Pacing)
Vary information density across the deck to maintain audience attention. Follow a "tension curve":

| Position | Tension | Design Approach |
|----------|---------|-----------------|
| Cover | High (brand-forward) | #D2D2C6 background, texture, large logo |
| Introduction (1-2 slides) | Calm | #D2D2C6 statement slide, generous whitespace |
| Main body | Medium-High (info-dense) | #FFFFFF background — dashboards, tables, charts |
| Transition points | Intentional "pause" | #D2D2C6 statement slide or single KPI number |
| Conclusion | High | #FFFFFF background — KPI summary + Next Actions |

**Key principle**: Alternate between dense slides and sparse "breathing" slides. Never stack more than 3 high-density slides without inserting a visual pause.

### Pull Quote / Highlight Box
Use to visually distinguish key conclusions or insights from surrounding content:
- **Beige Dark box**: #6D695D background → text inside MUST be #FFFFFF 22pt. Rounded corners (8-12px), generous padding. Use once per 3-4 slides for visual accent
- **Left border accent**: 4px solid #6D695D vertical line on left + indented quote text in black
- Purpose: Break monotony of uniform text, create moments where the brand color "surfaces" within the information flow

### Recommended Presentation Length
- **5-8 slides**: Weekly reports, concise proposals
- **10-15 slides**: Project proposals, strategy presentations
- **15-25 slides**: Detailed analysis reports, business plans

## 6. Voice & Tone

### Slide "Narrator" Personality
- Calm and composed
- Honest and fact-driven
- Talks about excitement without exaggeration
- High resolution on users / frontline operations

### Writing Rules
- **Use である調 (formal declarative) consistently**
- 1 slide = 1 message
- Keep sentences short (approximately 2 lines maximum per sentence)
- Do not omit subjects (explicitly state WED / ONE, etc.)

### Recommended Content Structure
All content slides should follow this pattern:

**Conclusion → Evidence → Next Action**

Example:
- Conclusion: "◯◯である" (It is ◯◯)
- Reason: "◯◯のためである" (Because ◯◯)
- Next: "◯◯を実施する" (Execute ◯◯)

### Good Examples (Recommended phrasing)
- "Use WED's beige as 'texture' on the cover, organize information on a white base for body slides"
- "Because materials are frequently merged and reused, consistency tends to break down"
- "Duplicate this template to create"

### Bad Examples (Avoid these)
- "Just make it look good somehow"
- "Go with the vibe, please"
- Hyperbole ("absolutely," "guaranteed," "world's best," etc.)
- Chains of abstract modifiers ("innovative," "groundbreaking," "next-generation," etc.)

## 7. Visual Identity DO / DON'T

### Goal
Create a state where materials look like "the same company's materials" even when duplicated or combined.

### DO (Good examples)

**Strong brand on cover, strong information on body slides**
- Cover: Make WED's beige the star for brand identification (use as texture, not flat fill)
- Body: White-based, generous whitespace, text and diagrams as focus

**Define fixed components first so pages look consistent**
- Unify chapter title styles (headings, whitespace, simple motifs)
- Align diagram border thickness, rounded corners, and arrow shapes
- Use Beige Dark (#6D695D) as the accent color throughout

**Unify Japanese fonts with Zen Kaku Gothic New**

### DON'T (Bad examples)

**Heavy use of gradients and decoration in body slides**
- Tone breaks down easily when slides are combined

**Photo style, shadows, and dimensionality change per page**
- Causes individual slides to look like a different company

**Mixed icon/illustration styles**
- Inconsistent line thickness, rounded corners, and shadows destroy visual unity

## 8. Image Guidelines

### Core Principle
Images serve understanding and decision-making, not "atmosphere." Emotional elements (excitement) are concentrated on covers, chapter titles, and closings.

### Recommended Image Tone (Priority Order)

**1. Color as Texture (Top Priority)**
- Use beige as "texture" on chapter titles and emphasis slides (brush/grain-like texture feel)
- This is not image insertion — it's texture expression through how color is applied
- Avoid flat fills; create a warm surface feel characteristic of WED

**2. Data Visualization (Actively Use)**
When quantitative data exists, actively generate charts. Do NOT skip charts or replace them with tables.
- **Chart types**: Bar chart (comparisons, rankings), line chart (trends over time), pie/donut chart (proportions, share), stacked bar (composition comparison), progress bar (target vs actual)
- **Color usage**: #6D695D (Beige Dark) as primary chart color. #D2D2C6 (Beige Light) as secondary/comparison color. No other colors.
- Minimize grid lines, no 3D effects
- Always include axis labels and insight captions
- Every deck with quantitative data must include at least 2 charts. Charts over tables when data allows — visual variety prevents monotony
- **Numeric context patterns**: Use ▲/▼ direction symbols for changes (e.g., ▲+32%), inline badges (small rounded tags in Beige Dark) for YoY/target comparison, and progress bars (#6D695D fill, Beige Light remainder) for completion metrics

**3. Product Images / Screenshots (Only When Needed)**
- Use only when feature explanation or experience evidence is required
- No excessive device mockups or decoration; use annotations to aid understanding

**4. People / Photography (Limited to Internal Communications)**
- Choose low-saturation, non-staged images
- Avoid stock photo feel (excessive smiling, excessive sparkle)

### Shape-Based Illustrations (Encouraged)
Build visual compositions using native slide shapes (rectangles, circles, triangles, lines, arrows) in brand colors. Shape-based illustrations add visual richness and brand personality without relying on external images. Examples: conceptual diagrams, abstract process visuals, geometric compositions, layered shape infographics.

### Image Usage to Avoid
- **Inserting external images**: photos, icons, clip art, AI-generated image files — all prohibited
- Photo style changing per page (inconsistent saturation/contrast)
- Background images that reduce readability
- Mixed icon/illustration styles (inconsistent line weight, rounded corners, shadows)
- Note: Data visualization (charts, graphs, diagrams) and native shape compositions are recommended exceptions

## 10. Prohibitions

### Design Prohibitions
- Gradient backgrounds
- 3D effects or drop shadows
- Colors outside the brand palette
- Decorative borders or shadows
- Excessive animation or transitions

### Content Prohibitions
- Information overload (no more than 5 elements per slide)
- Font sizes too small (below 14pt). Body text below 18pt
- Casual use of clip art or stock materials
- Hyperbole or chains of abstract modifiers

### AI Generation Prohibitions
- Using the same layout pattern on all slides (vary patterns; monotonous decks are a common AI failure)
- Constructing slides entirely with bullet points (use charts, tables, matrices, KPI cards instead)
- Decks with zero charts/graphs — every deck with quantitative data must include at least 2 charts (bar, line, pie, progress bar). Never replace charts with tables when data is quantitative
- Vague slide titles like "〜について" or "〜の概要" (titles must state a conclusion or insight)
- Using only one background color throughout (mix #FFFFFF content slides with #D2D2C6 brand slides; never all-white or all-beige)

### Image Prohibitions
- **Inserting external images**: AI-generated image files, photos, icons, clip art — all prohibited
  - ※ Data visualization and native shape-based compositions are encouraged
- Mixed photo styles across pages
- Background images that reduce readability
