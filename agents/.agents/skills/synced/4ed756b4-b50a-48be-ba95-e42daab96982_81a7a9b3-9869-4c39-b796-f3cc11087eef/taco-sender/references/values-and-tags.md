# WED Values & Competencies ハッシュタグ一覧

タコス投稿時に使用するハッシュタグ。発言内容から最も近い1〜2個を自動選定する。

## Values → Competencies 対応表

| Value | Competencies |
|---|---|
| #未来を問おう | #理想を描く, #自らの意思を持つ, #本質を落とさない |
| #世界観ファースト | #逆算して考える, #チャレンジングな選択をする, #やりきる |
| #一人ではできないことをしよう | #相手を理解し受け入れる, #とことん対話する, #惜しみなくシェアする |

## ハッシュタグ選定ガイド

以下の行動パターンに基づいて判定する。

- **#理想を描く** — ビジョンを示した、未来の姿を語った、あるべき姿から逆算した提案
- **#自らの意思を持つ** — 自分の意見を明確に伝えた、主体的に判断・行動した
- **#本質を落とさない** — 表面的でなく根本原因に踏み込んだ、妥協せず品質を追求した
- **#逆算して考える** — ゴールから逆算した計画・段取り、先を見据えた行動
- **#チャレンジングな選択をする** — 安全策でなく挑戦的な道を選んだ、新しいことに踏み出した
- **#やりきる** — 困難な状況でもやり遂げた、最後まで責任を持った、体調が悪くても動いた
- **#相手を理解し受け入れる** — 相手の立場や気持ちを汲んだ、多様な意見を受け入れた
- **#とことん対話する** — 深い議論をした、壁打ちに付き合った、納得いくまで話し合った
- **#惜しみなくシェアする** — 知識・ノウハウを共有した、レクチャーした、ドキュメント化した
