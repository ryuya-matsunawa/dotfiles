# プロダクトナレッジベース Ask

このスキルの手順の本体はNotionで管理している。ここには読み込み方と、利用者の環境チェックだけを書く。手順を変えたいときはNotionのページを編集する（このファイルは触らない）。

利用者は事前説明を受けていない前提で動く。準備が足りなければ、このスキルがその場で案内する。

## 実行手順

1. Notionの指示書ページを取得する: `252faa9007944c359397ce2980ed262a`（🔎 Ask）
   - 取得できなければ「環境チェック」の Notion 行に従って止まる。記憶や推測で手順を補って回答しない。
2. 取得した内容の「手順」と「回答フォーマット」に**そのまま従って**回答する。
   - 対象DB: `2789effef6e24acc89b15e341c11dfa6`（data source `collection://b021afcc-9bd7-47c4-9695-cda3f6f387a0`）
   - KBの「根拠・ソース」にリポジトリ／ファイルが書いてあれば、まずそのファイルを直接確認する（例: `gh api repos/wedinc/bellroy/contents/<path>`）。
3. 指示書の手順4でKBの追加・更新をユーザーが承認したら、`product-kb-add` スキルに引き継ぐ。
4. 回答の最後に、下の「環境チェック」で使えなかったソースがあれば「🔧 セットアップのお願い」を付ける。全部使えたら何も付けない。

## 環境チェック

各ソースは実際に使ってみて判定する（事前の確認だけのために余計な呼び出しはしない）。

| ソース | 使えないときの判定 | 案内する対処 |
|---|---|---|
| Notion（必須） | Notionツールが無い／認証エラー | Claudeの設定 > コネクタ で Notion を接続。**これが無いと回答できないので、ここで止まる** |
| Notion 権限 | Askページが見つからない／権限エラー | 「プロダクトナレッジベース」ページの閲覧権限を管理者に依頼。ここで止まる |
| Slack / Linear / Google Drive | ツールが無い／認証エラー | Claudeの設定 > コネクタ で該当サービスを接続 |
| GitHub（Claude Code） | `gh` が無い／`gh auth status` が未ログイン／`wedinc` のリポジトリが 404 | 下記「GitHubのセットアップ」 |
| GitHub（Claudeアプリ） | GitHubツールが無い | コネクタで GitHub を接続。難しければ「コードの裏取りは Claude Code で聞くと確実」と伝える |

### GitHubのセットアップ（Claude Code）

- `gh` が無い → 「インストールしてよいですか？」と聞き、承諾されたら `brew install gh` を実行する。
- 未ログイン → ログインは対話操作が必要なので、ユーザーにターミナルで `gh auth login --hostname github.com --git-protocol https --web` を実行してもらい、表示されたコードをブラウザに入れて Authorize（wedinc の Grant も）するよう案内する。個人メールのGitHubアカウントでよい。
- ログイン済みでも `wedinc/bellroy` が 404 → そのGitHubアカウントが wedinc 組織に未参加。GitHub管理者に招待を依頼するよう案内する。

### 「🔧 セットアップのお願い」の書き方

- 使えなかったソースと、それぞれの対処を1行ずつ。最後に詳しい手順として紹介ページの「はじめに」へのリンク https://app.notion.com/p/3866a6dcb9034a4e9c5dbab04eebce48 を付ける。
- 回答本体の「補足/未検証点」にも、どのソースを確認できなかったかを必ず書く（例:「GitHub未接続のため実装は未確認」）。
