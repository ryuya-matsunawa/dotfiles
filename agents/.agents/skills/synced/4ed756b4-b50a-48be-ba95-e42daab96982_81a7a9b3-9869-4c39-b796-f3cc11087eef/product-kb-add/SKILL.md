# プロダクトナレッジベース Add

このスキルの手順の本体はNotionで管理している。ここには読み込み方と、利用者の環境チェックだけを書く。手順を変えたいときはNotionのページを編集する（このファイルは触らない）。

利用者は事前説明を受けていない前提で動く。準備が足りなければ、このスキルがその場で案内する。

## 実行手順

1. Notionの指示書ページを取得する: `9ae1f73de555403faec25c607ed7ce75`（➕ Add）
2. 取得した内容の「手順」と「ページ本文テンプレート」に**そのまま従って**登録する。
   - 対象DB: `2789effef6e24acc89b15e341c11dfa6`（data source `collection://b021afcc-9bd7-47c4-9695-cda3f6f387a0`）
   - 書き込む前に data source のスキーマを取得し、Domain／Feature などの選択肢は既存の値から選ぶ。
3. DBへ書き込む前に、作成・更新する内容（タイトル・属性・本文の要点、更新かコンフリクト化か）をユーザーに提示し、承認を得てから書き込む。
4. 「検証済」（人確認）はAIが設定しない。指示書の自動検証条件をすべて満たすときだけ「検証済（自動）」にする。

## 環境チェック

`product-kb-ask` スキルの「環境チェック」と同じ基準・同じ案内をする。Add固有の点だけ以下。

- DBへの書き込みが権限エラー → 「プロダクトナレッジベースDBの編集権限を管理者に依頼してください」と伝え、登録しようとした内容（タイトル・属性・本文）を回答に残して止まる。
- GitHubを確認できなかった場合、コードに関わる内容は「検証済（自動）」にせず「未検証」とし、本文の「未解決・要検証点」に「GitHub未確認」と書く。
- 足りないものがあれば最後に「🔧 セットアップのお願い」を付け、紹介ページ https://app.notion.com/p/3866a6dcb9034a4e9c5dbab04eebce48 の「はじめに」へリンクする。
