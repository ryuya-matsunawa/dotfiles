# ONE Brand Design Definition v2.0
## Slide Generation Reference

---

## 0. Brand Story

### Product Identity
ONE is WED Inc.'s flagship BtoBtoC platform that transforms receipt data into marketing and analytics value. Users photograph receipts to earn cashback rewards; aggregated purchase data powers enterprise advertising, promotion, and analytics.

### Brand Hierarchy
| Brand | Position | Description |
|-------|----------|-------------|
| **ONE** | Flagship Product | BtoBtoC platform. Receipt cashback (toC) + purchase data analytics (toB) |
| **WED** | Parent Company | Technology and operational foundation. Use only in corporate context |
| **PMN** | B2B Extension | Performance Media Network. Scales ONE's data assets to external media |

### Naming Rules
- "ONE" = always full caps. Font: Brandon Grotesque Black.
- "WED" = parent company context only. Product slides use ONE as subject.
- "PMN" = full name on first mention, abbreviation thereafter.

### "ONE-ness" Expression
Data-first, evidence-driven communication. Express through numbers and facts, not adjectives:
- **Every insight backed by data** — receipts processed, conversion rates, ROI metrics
- **Precision over enthusiasm** — "前年比+32%増" not "大幅に増加"
- **Platform scale visible** — user counts, data volume, partner network size

## 1. Color Palette

### Core Colors (Complete — no other colors exist)
| Name | HEX | Role | Usage |
|------|------|------|-------|
| ONE Green | #3EE3A6 | Accent secondary | Charts primary, progress bars, tags, graph fills |
| ONE Dark Green | #00D184 | Accent primary | KPI numbers, highlights, CTA, graph secondary |
| ONE Light Green | #D7FFF0 | Accent light | Badge BG, subtle highlight, table highlight cells |
| Black | #000000 | Text / Table header | Body text, slide titles, table header row BG |
| ONE Light Gray | #F0F3F6 | Card / Alt-row BG | Cards on white BG, table alt-rows, sub-sections |
| ONE Dark Gray | #8C909B | Structure | Rules, borders, sub-headers, footnotes, graph tertiary |
| White | #FFFFFF | Default BG | Primary background (70%+ of slides) |

**Only these 7 colors exist. No Red, Blue, Pink, Yellow, Orange, Purple.**

### Slide Background System (dual rhythm)
- **Content slides** (tables, dashboards, charts, data-heavy): #FFFFFF background (DEFAULT — 60-70% of slides)
- **Brand slides** (statement, pull quote, visual pause): #F0F3F6 background (30-40% of slides)
- Mix both in every deck. Creates visual rhythm. Never all-white or all-gray.
- **#000000 is NOT a slide background color.** Black is for text and table header rows only. Never use black as slide background.

### Color Pairing Rules (mandatory — check every element)
| Background | Cards/Sections | Text | Accent |
|------------|---------------|------|--------|
| #FFFFFF (White) | #F0F3F6 (Light Gray) | #000000 | #00D184 / #3EE3A6 |
| #F0F3F6 (Light Gray) | #FFFFFF (White) | #000000 | #00D184 / #3EE3A6 |

- **NEVER**: Same color on same color (e.g., #F0F3F6 card on #F0F3F6 BG = invisible = broken layout)
- **NEVER**: #000000 as slide background (black = text and table headers only)
- **Accent greens NEVER for**: Slide backgrounds, large card fills (>25% area), body text, headers

### Chart Color Sequence
1. Primary: #3EE3A6 (ONE Green)
2. Secondary: #00D184 (ONE Dark Green)
3. Tertiary: #8C909B (ONE Dark Gray)
4. Quaternary: #F0F3F6 (ONE Light Gray)
5. Quinary: #000000 (Black — sparingly)

## 2. Typography System

### Font Stack
| Context | Font | Weight | Size | Color |
|---------|------|--------|------|-------|
| Product name "ONE" | Brandon Grotesque | Black | Context-dependent | #000000 / #FFFFFF |
| Numbers (KPI display) | コトノデ (Kotonode) | Bold | 48-72 pt | #00D184 |
| Slide title | Noto Sans JP | Bold | 28-32 pt | #000000 |
| Sub-header | Noto Sans JP | Bold | 20-24 pt | #000000 |
| Body text | Noto Sans JP | Regular | 18-20 pt | #000000 |
| KPI label | Noto Sans JP | Regular | 16 pt | #8C909B |
| Footnote / Source | Noto Sans JP | Regular | 14 pt | #8C909B |

### FORBIDDEN Sizes
10pt, 12pt — these sizes do NOT exist in ONE slides. Body text must be 18pt+.

### Text Density Guidelines (per element — controls readability without restricting layout)
| Element | Max Words | Rationale |
|---------|-----------|-----------|
| Slide title | 10 words | Conclusion, not topic description |
| Bullet point | 12 words each | One idea per line |
| Table cell | 10 words | Scannable at glance |
| Card body | 50 words | Less text = larger effective font |
| KPI label | 5 words | Concise metric name |

Less text per element forces larger, more readable fonts. All text must be readable from the back of a meeting room.

## 3. Design Tone & Manner

### Core Principles
- **Data-dense**: Consultant-quality information density (McKinsey/BCG level)
- **Flat & clean**: No shadows, no gradients, no 3D effects
- **Sharp & modern**: Clean lines, generous whitespace, grid-based order

### Layout Principles
- One slide = one message (title states the conclusion)
- Left-aligned by default; centering only for statement slides
- Grid-based, orderly layouts with clear hierarchy
- Border-radius: 8 px max on cards and content boxes
- Lines/rules: 1-2 px, #8C909B or #00D184

### Spacing
- Slide edge margins: 40 px+ (generous whitespace)
- Title-to-body gap: 1.5× title height
- Card-to-card gap: ~5% of card width
- Never push content to edges. Always maintain breathing whitespace.
- Content area: Title occupies top 8-15%. Content fills from 15% to 90% of slide height.

### Element Count Guidelines (per slide type)
| Slide Type | Recommended Max | Rationale |
|------------|----------------|-----------|
| Statement / Single KPI | 2-3 elements | Maximum impact with minimum information |
| Text / Message | 3 elements (title + conclusion + evidence) | One slide = one message |
| KPI Dashboard | 3-4 KPI cards + 1 chart/insight | More than 4 KPIs loses focus |
| Chart / Graph | 1 chart + title + 1 insight line | Let the chart speak |
| Data Table | 5-7 rows × 4-5 columns max | Beyond this = handout material |
| Comparison Cards | 2-3 columns | Cards serve as natural dividers |

## 4. Slide Composition Patterns

### Structural Slides (generated using ONE Slide Masters)
Cover, Table of Contents, Section Divider, Closing — generated using defined Slide Masters (ONE_COVER, ONE_SECTION, ONE_CLOSING). Always include Cover as first slide and Closing as last slide.

### Content Layout Patterns (vary — never repeat same pattern 3x consecutively)
| Pattern | Frequency | Structure |
|---------|-----------|-----------|
| **KPI-Row** | PRIMARY (30%+) | Top: 3-4 metric cards (number 48-72pt #00D184, label 16pt #8C909B, card BG #F0F3F6). Bottom: insight paragraph or chart |
| **Left-Right 60/40** | Regular | Left 60%: chart/data table/visualization. Right 40%: 2-3 key takeaways. Divider: 2px #8C909B vertical rule |
| **Full-Width Table** | Regular | Header: #000000 BG + #FFFFFF text. Alt-rows: #F0F3F6/#FFFFFF. Highlight cells: #D7FFF0 BG. Border: 1px #8C909B. 4+ rows |
| **Statement+Evidence** | Regular | Top: 24-28pt bold conclusion. Bottom: supporting data (chart or KPI cards) |
| **Waterfall/Funnel** | Regular | Horizontal bar progression. Color: #3EE3A6 → #00D184 (light to dark). Labels: right-aligned values. Key step = #00D184 filled |
| **Comparison 50/50** | Regular | Two equal columns. Contrasting headers (Before/After, Plan A/B). 2px #8C909B vertical divider |
| **Process Flow** | Regular | 3-5 rounded nodes (#F0F3F6 BG, #000000 text) connected by thick visible #8C909B arrows/lines (2-3px, MANDATORY — disconnected nodes = broken layout). Key step: #00D184 filled node (#FFFFFF text) |
| **Timeline/Roadmap** | Regular | Horizontal sequence of rounded milestone nodes connected by #8C909B lines/arrows. Key milestones: #00D184 filled (#FFFFFF text) |

### Visual Rhythm (Slide Pacing — tension curve)
| Position | Tension | Design Approach |
|----------|---------|-----------------|
| Opening (1-2 slides) | Medium | Statement slide on #F0F3F6 or single bold KPI on white |
| Main body | High (info-dense) | #FFFFFF background — dashboards, tables, charts |
| Transition points | Intentional "pause" | #F0F3F6 brand slide with single statement or KPI |
| Conclusion | High | KPI summary + Next Actions on white |

**Key principle**: Alternate between dense slides and sparse "breathing" slides. Never stack more than 3 high-density slides without a visual pause.

### Pull Quote / Highlight Box
- **Dark Gray box**: #8C909B background → text #FFFFFF, 22pt. Rounded corners (8px). Use once per 3-4 slides for visual accent.
- **Green accent badge**: Inline #D7FFF0 background + #000000 text for highlighting key numbers or terms within body text.
- Purpose: Break monotony, create moments where brand personality surfaces within information flow.

## 5. Charts & Data Visualization

### Core Principle
When quantitative data exists, CREATE charts directly. Do NOT skip charts or replace them with tables. Every deck with quantitative data MUST include at least 2 charts. Charts tell the story faster than tables.

### Chart Types & Color Usage
| Type | Usage | Color |
|------|-------|-------|
| **Bar chart** | Comparisons, rankings, before/after | #3EE3A6 primary, #00D184 secondary |
| **Line chart** | Trends over time | #3EE3A6 line, #8C909B grid |
| **Pie/Donut** | Proportions, share breakdowns | #3EE3A6 primary segment, #00D184 secondary, #8C909B others |
| **Stacked bar** | Composition comparisons | #3EE3A6 + #00D184 + #8C909B segments |
| **Progress bar** | Target vs actual, completion | #00D184 fill on #F0F3F6 background |

### Numeric Context Patterns
- Direction symbols: ▲/▼ for changes (e.g., ▲+32%)
- Inline badges: Small rounded tags in #D7FFF0 for YoY/target comparison
- Progress bars: #00D184 fill, #F0F3F6 remainder
- Source/period: Every chart and KPI must cite source or note "推定" / "社内データ"

### Chart Style
- Minimize grid lines, no 3D effects
- Always include axis labels and insight captions
- When data can be shown as either table or chart, prefer chart
- Tables alone create visual monotony — charts make the story visible

## 6. Shape-Based Illustrations (Encouraged)

### Core Principle
NEVER insert external images (photos, icons, clip art, AI-generated images). Instead, BUILD visual compositions using native slide shapes.

### Recommended Compositions
- Combine rectangles, circles, lines, arrows in brand colors
- Build pyramids, funnels, step diagrams, timelines, Gantt-style bars
- Create conceptual diagrams and abstract process visuals
- Use #3EE3A6 / #00D184 for key elements, #8C909B for structure, #F0F3F6 for background shapes

Shape-based compositions add visual richness and brand personality without relying on external image files.

## 7. Voice & Tone

### Slide "Narrator" Personality
- Data-driven and precise
- Assertive without exaggeration
- Shows platform scale through numbers
- Quantifies everything — no vague modifiers

### Writing Rules
- **である調 + 体言止め** (assertive, concise) — NEVER です/ます
- 1 slide = 1 message
- Keep sentences short (max 2 lines per sentence)
- Explicitly state ONE as subject (never omit)
- Every data point must cite source or note "推定" / "社内データ"

### Recommended Content Structure
**結論 → 根拠データ → 示唆/Next Action**

Example:
- 結論: "レシートデータ活用により広告ROIが32%向上"
- 根拠: KPIチャート + 前後比較データ
- 示唆: "Q2に全広告主へ本機能を展開"

### Title Rules (mandatory)
- Titles MUST state a conclusion or insight
- NEVER use "〜について" or "〜の概要" as titles (= topic labels, not insights)
- Good: "レシートデータ活用でCVR 2.3倍に改善"
- Bad: "レシートデータの活用について"

## 8. Visual Identity DO / DON'T

### DO
- **White-dominant content slides** with #F0F3F6 cards for structure
- **Green accents sparingly** — KPI numbers, chart fills, progress bars, badges
- **Light Gray brand slides** (#F0F3F6, 30-40% of deck) for visual pause and statements
- **Consistent card styling** — same border-radius, same spacing, same typography
- **Data visualization first** — charts over prose, numbers over adjectives

### DON'T
- **Decorative background shapes** — never add circles, blobs, geometric decorations to backgrounds
- **Gradients, shadows, 3D effects** — flat design only
- **Green on large areas** — accent greens are for highlights only, never backgrounds or large fills
- **Same layout 3x in a row** — vary patterns to maintain visual interest
- **Bullet-only slides** — use charts, tables, matrices, KPI cards instead
- **Table-only decks** — include charts for visual variety when data is quantitative
- **All-white decks** — mix in #F0F3F6 brand slides for rhythm (30-40%)
- **External images** — no photos, icons, clip art, AI-generated images (native shapes only)
- **Vague titles** — "〜について" or "〜の概要" = broken title (must be insight/conclusion)

## 9. AI Generation Prohibitions

### Layout Prohibitions
- Using the same layout pattern 3x consecutively (vary patterns)
- Constructing slides entirely with bullet points (use charts, tables, matrices)
- Decks with zero charts when quantitative data exists (minimum 2 charts per deck)
- Large empty bottom halves — stretch content to fill 15%-90% of slide height

### Color Prohibitions
- Accent green (#3EE3A6 / #00D184) as slide background or large card fill
- Same color on same color (e.g., #F0F3F6 on #F0F3F6 = invisible = broken)
- Colors outside the 7-color palette
- Gray body text (body text is always #000000)

### Content Prohibitions
- Vague slide titles ("〜について" / "〜の概要" = broken title)
- Hyperbole or chains of abstract modifiers
- Data without source citation
- です/ます tone (must be である調)

### Technical Prohibitions
- Inserting external images (photos, icons, clip art, AI-generated files)
- Drop shadows, gradients, 3D effects
- Decorative background shapes (circles, blobs, geometric decorations)
- Font sizes below 14pt. Body text below 18pt.
- Generating cover, section divider, or closing slides WITHOUT using the defined Slide Masters (ONE_COVER, ONE_SECTION, ONE_CLOSING)
