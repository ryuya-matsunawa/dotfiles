# Receipt Analysis for Solutions Skill

スキル起動時に、以下の手順で指示を読み込み、その内容に従って処理を実行してください。

1. まず以下のNotion DBページの指示を読み込んでください：
   https://www.notion.so/36cd48a3c2cb815086c5f1c5e2d22a97

2. Notionが取得できない場合は、以下のGoogle Driveフォルダ内にある最新のmdファイルを読み込んでください：
   フォルダID: 1PpFE4EqvUvSRwwobamB8LCSN3HD_GlSX
   手順：
   - GDriveツールでフォルダ内の `receipt-analysis-for-solutions` を含むファイルを一覧取得する
   - `diff` を含むファイル名は除外する
   - ファイル名が `receipt-analysis-for-solutions_YYYYMMDD.md` パターン（末尾に8桁の日付）に一致するものを抽出する
   - ファイル名末尾のYYYYMMDD（8桁数値）が最大のものを1件選択して読み込む
   - 該当するファイルがない場合は、modifiedTimeが最も新しいファイルにフォールバックする
